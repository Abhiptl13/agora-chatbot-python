# Agora Assistant Chatbot - Python MVP

## Project Overview

The Agora Assistant Chatbot is a Python Flask-based web application designed to support students, teachers, and administrators within the Collège Agora intranet environment.

The system provides role-based access to academic information, document resources, appointment booking services, and an AI-powered assistant capable of answering common institutional questions.

This project represents the Python equivalent version of the main team project and follows the same objectives, requirements, documentation standards, and sprint planning process.
