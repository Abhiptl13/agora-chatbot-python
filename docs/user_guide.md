## Using the Chatbot

1. Login to the system.
2. Open AI Assistant.
3. Type a question.
4. Click Send.
5. Review the answer.
6. Check the source shown below the answer.

---

## Using Document Library

1. Open Document Library.
2. Enter a search keyword.
3. Click Search.
4. View matching documents.

---

## Booking an Appointment

1. Open Appointment Booking.
2. Fill in required information.
3. Select advisor.
4. Choose date and time.
5. Submit request.

---

## Viewing History

1. Open History page.
2. Review previous conversations.
3. View answer sources and timestamps.

---

## Logging Out

Click Logout in the navigation bar to end the current session safely.
