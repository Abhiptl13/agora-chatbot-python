Project Highlights

Built as a complete Python version of an AI campus assistant.

This project combines Flask, MongoDB, role-based authentication, real PDF uploads, AI document search, chatbot memory, appointment management, and deployment-ready structure. The design focuses on simplicity, stability, and a professional College Lasalle portal experience.
